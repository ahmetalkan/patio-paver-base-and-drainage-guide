# Patio Paver Base, Drainage and Material Guide

A homeowner reference explaining paver base excavation and lift compaction, comparing clay brick and concrete pavers, locking joint sand and edge restraints, and permeable stormwater design with CMHA, US EPA, and 811 sources.

This is a free, standalone mini-resource published on GitHub Pages:

- Homepage — patio paver installation and base preparation overview: `https://ahmetalkan.github.io/patio-paver-base-and-drainage-guide/`
- Subpage — excavation depth, compacted aggregate lifts, and open-graded bases: `https://ahmetalkan.github.io/patio-paver-base-and-drainage-guide/base-depth-and-compaction.html`
- Subpage — comparing kiln-fired clay brick and precast concrete pavers: `https://ahmetalkan.github.io/patio-paver-base-and-drainage-guide/clay-brick-vs-concrete-pavers.html`
- Subpage — installing edge restraints and activating polymeric joint sand: `https://ahmetalkan.github.io/patio-paver-base-and-drainage-guide/joint-sand-and-edge-restraints.html`

It cites public pages on [paverlabs.com](https://paverlabs.com/) and official reference sources listed at the bottom of each page. Nothing here is a substitute for advice from a qualified professional.
